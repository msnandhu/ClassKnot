# ClassKnot

**One Platform. Every School Connection.**
*Connecting Campus Operations to Parents Trust*

Branding website for **ClassKnot**, the school management software by **Zeshin** (Beyond the Build).
It connects students, parents, teachers and school management on one platform.

## What's here

| File | Purpose |
|---|---|
| `index.html` | The full website: one self-contained page, no build step |
| `assets/` | ClassKnot logo (light and dark versions) and logo mark |
| `og-image.jpg` | Share preview image for WhatsApp, LinkedIn, Facebook and X |
| `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Browser and home-screen icons |
| `site.webmanifest` | App manifest |
| `robots.txt`, `sitemap.xml` | Search engine files |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

Upload the repository contents to the root of any static host (GitHub Pages, Vercel, Netlify or cPanel).

**Before going live, set your real domain.** The site currently uses `https://www.classknot.in` as a placeholder in:
- `index.html` (canonical URL, Open Graph and Twitter tags, structured data)
- `robots.txt`
- `sitemap.xml`

After deploying, add the domain to **Google Search Console** and submit `sitemap.xml`.
